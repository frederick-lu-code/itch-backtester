# M4 walkthrough: risk

## What was added

- `include/itchbt/risk/risk.hpp`: `RiskGate` with pre-trade checks, per-symbol position, cost
  and PnL, and the kill switch.
- Engine wiring: `submit()` calls `check_and_reserve`; order updates reaching the strategy side
  call `on_fill`, `on_closed` or `on_order_done`; top-of-book changes call `on_top_of_book`;
  a trip calls `trip_kill_switch()`, which records the event and cancels every open order.
- `tests/unit/risk_test.cpp`, kill-switch tests in `tests/integration/engine_test.cpp`,
  `configs/kill_switch_demo.toml`.

## The checks, in order

Kill switch, validity, session, halt, order quantity, order notional, price collar, worst-case
position, open-order count, gross notional, rate limit. The first failure is the reason code.
A passing order reserves its exposure and spends a rate-limit token in the same call.

## Done when

- Each check is tested at, just under and just over its limit.
- A config that trips the kill switch behaves as specified: the loss-limit test shows the
  resting order cancelled at the trip and every later order rejected with `kill_switch`, with
  the trip and the rejects in `risk.bin`. On the real day `configs/kill_switch_demo.toml`
  trips at 09:30:51 and rejects the 14,017 orders that follow.

## Questions a reviewer might ask

- **Why is PnL stored doubled?** So the mid of an odd spread is exact. See decision R1.
- **Can the risk gate itself overflow?** It could, for an absurd order; UBSan found it. There
  is now a hard notional ceiling. See `DEBUGGING.md`.
- **When does the gate learn about a fill?** When the update reaches the strategy side, after
  the acknowledgement latency. Until then the order's full size still counts as open, which is
  the conservative direction.
- **Does the kill switch flatten positions?** No. The specification says cancel and reject;
  it does that.
- **How is the Python PnL check related?** `analysis/report.py` recomputes position, realised
  and unrealised PnL from `fills.bin` and `bbo.bin` and a test requires exact equality with
  the gate's figures in `run.json`.
